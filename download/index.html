Install

  1. Download the zip. It is the only file you need.
  2. Extract it. You should see CrownAndConquest.exe.
  3. Double-click the exe.
  4. Windows SmartScreen may show a blue window, because this build is not signed. Choose More info, then Run anyway.
  5. On the title screen choose Play, then set your people, the map size, the difficulty, and a seed.

Controls

  • WASD scrolls the valley. The map edge eases into the scroll.
  • Left-drag selects tillers and soldiers. A click selects one.
  • Right-click commands them: ground to move, an enemy to attack, berries, trees, gold, or stone to gather.
  • N stops the current order.
  • Space selects an idle Tiller. The Idle count sits in the top bar.
  • Esc opens the pause menu: Resume, Restart this seed, New valley, Main menu, and Quit. Esc resumes.
  • Hover a unit, building, or resource for its name, owner, hit points or amount, and role. A building under construction shows its percent.
  • Hover a command button for its name, hotkey, cost, and role. The letter on the button is the hotkey.
  • Build a Homestead before the population cap stops you.
  • The minimap sits at the lower right.
