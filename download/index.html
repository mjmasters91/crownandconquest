Play on iPhone / in browser

iPhone and the browser

The browser build is a portrait page at crownandconquest.net/play. It is one thread, so it runs without special server headers. Add it to the home screen if you want an icon.

  1. On iPhone, open crownandconquest.net/play in Safari.
  2. Tap Share.
  3. Tap Add to Home Screen.
  4. Open the game from the new home screen icon.
  5. The first tap turns the sound on.

On a computer, open the same page in a current browser. The window is portrait.

Install on Windows

  1. Download the zip. It is the only Windows file you need.
  2. Extract it. You should see CrownAndConquest.exe.
  3. Double-click the exe.
  4. Windows SmartScreen may show a blue window, because this build is not signed. Choose More info, then Run anyway.

v0.4.0

  • Dragging a card onto the arena works with a mouse and with a finger, on Windows, in the browser, and on iPhone.
  • Tap a card, then tap the grass, and it deploys.
  • Companion models are rebuilt, with faces, team colors, and animations.
  • Castle-style towers, a moving river, bridges, and decorations.
  • A bigger card bar with more space between cards, a smaller Next card, and a range ring while you drag.

  • A real 3D arena.
  • Towers and all 18 original companions, with animations.
  • 3D spell effects.
  • New bright sky-blue and gold menus.
